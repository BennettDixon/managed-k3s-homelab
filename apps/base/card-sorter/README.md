# card-sorter

The card-sorting machine's two services (spec: the private card-sorter repo, `docs/specs/inventory.md` and `docs/specs/identify.md`; plan `docs/software-plan.md`). `inventory` owns every tray's manifest, the only record of where ~7,000 cards are: one SQLite file on `local-path`, one writer, `Recreate`, a Litestream sidecar replicating it to the bulk NAS over SFTP by tailnet name (`litestream.yml`), seat-crop images beside it, the house caller-token map with the class per caller in `callers.yaml`, exposed as `http://inventory/` to the machine's Pi and the workbench. `identify` (PR 2) turns a seat photo into a printing against a local Scryfall mirror on the NAS (the first NFS-backed volume, a static PV), with a weekly mirror CronJob and a catalogue refresh. Runbook: `docs/runbooks/card-sorter.md`; alerts ride the one Telegram route.
